# 《荒岛物语》开发大纲 v2.0 — 评审建议文档

**评审依据：** 大纲 v2.0 全文（一至七章）
**建议分级：** 🔴 必须处理（存在设计漏洞/卡关风险）｜🟡 建议优化（提升体验）｜🟢 可选增强（锦上添花）

---

## 一、🔴 高风险问题与必改项

### 1.1 暴风雨+食物腐烂存在"死局"组合（对应 1.1 / 1.2 / 4.5）

**问题：** 当前设计中：
- 暴风雨 → 捕鱼减半 + 帮工效率降 50%
- 天气周期 2~3 天，暴风雨可能连续触发
- 鱼保质期仅 3 天，玩家离岛期间"帮工可能饿死"

若玩家出海探索时老家连遇 2 次暴风雨，回岛后帮工全灭，且玩家无法干预（离岛期间时间正常流逝但玩家不在岛上）。**这会惩罚探索行为，与"造船出海是核心成长目标"矛盾。**

**落地方案：**
1. **增加保底食物源：** 在主岛加入"采集点——野生根茎/浆果"（阶段1"摘果丛"已有雏形，建议明确为：不受天气影响、产量低但稳定，每日产出 1~2 单位、保质期 10 天）。
2. **天气保底规则：** 状态机中禁止连续 2 次暴风雨（sunny → cloudy → rainy → stormy → sunny 已隐含此意，建议在代码中显式加约束：`stormy` 之后必定进入 `sunny`）。
3. **离岛保护机制：** 玩家不在主岛时，帮工饥饿不直接死亡，改为进入"虚弱状态"（效率降为 25%，不消耗死亡判定），玩家回岛后 1 天内可救治。**饿死改为警告而非惩罚。**
4. **出发前食物检查：** 玩家点击"出海探索"时，若库存食物不足以支撑帮工 5 天（按人数×每日消耗计算），弹出确认框："食物可能不够，是否仍然出发？"

### 1.2 铁矿石纯概率获取会造成无限期卡关（对应 2.1 阶段3 / 4.3 / 7 技术要点）

**问题：** 工具台需要"铁 3"，而铁的唯一来源是"深海钓鱼概率获得"。大纲 4.3 提到海面漂浮物有"铁矿石碎片"，但未说明碎片与铁矿石的兑换关系，也没有保底次数。运气差的玩家可能钓 50 次都凑不齐 3 个铁，科技树完全停滞。

**落地方案：**
1. **明确碎片合成规则：** 3 个铁矿石碎片 = 1 个铁矿石（在工具台或背包中合成）。
2. **钓鱼保底计数：** 深海钓鱼每 10 次必得 1 个铁矿石碎片或整块矿石（伪随机分布 PRD，代码中记录 `fishingSinceLastIron` 计数器）。
3. **漂浮物固定刷新：** 大海地图上每天固定刷新 2~3 个"铁矿石碎片漂浮物"（有独特外观，区别于普通木头/鱼漂浮物），给主动航行玩家确定性收益。
4. **UI 反馈：** 在科技树界面显示铁矿石获取进度（当前 x/3），避免玩家不知道该干嘛。

### 1.3 手动 WASD 航行与探索成本失衡（对应 4.2 / 4.3 / 4.4）

**问题：** 首次发现新岛需要手动 WASD 航行，且"逆风慢"。冰雪山岛最远，加上暴风雨逆风，首次航行可能长达数分钟纯开船，重复体验差；且航行期间主岛时间流逝（风险见 1.1）。

**落地方案：**
1. **顺风带设计：** 大海地图上放置 2~3 条"洋流带"（视觉上用箭头/水流粒子表示），进入后船速 ×2 且方向自动沿洋流，减少纯手动操作疲劳。
2. **首次航行事件化：** 首次前往新岛的航行过程中，随机触发 1~2 个海上事件（三选一卡牌形式）：遇到迷航商人（可交易）/ 风暴预警（选择返航或加速冲刺）/ 鲸鱼群（纯氛围+少量奖励）。让航行本身有内容而非纯位移。
3. **航行时间折算：** 手动航行消耗的时间按"游戏内小时"计，且航行期间主岛帮工消耗减半（"船在海上，岛民节衣缩食等你回来"），平衡探索风险。
4. **逆风惩罚降低：** 建议逆风速度为正常的 70%（而非更低），暴风雨天气禁止出海（出发按钮置灰+提示），从机制上避免"暴风雨逆风开船"的最差体验。

## 二、🟡 体验优化建议

### 2.1 香料性价比过低（对应 1.2 / 3.3 / 5.1）

**问题：** 香料保质期 +50%，冰块 ×3。玩家拿到冰块后香料完全失去价值，热带岛贸易线（第一个贸易岛）中后期会被抛弃。

**落地方案：**
1. **香料可加工：** 增加"香料腌鱼"配方（鱼 + 香料，在工具台制作）：保质期 3 天 → 12 天，且交易价值高于普通鱼。这给了香料长期用途。
2. **稀有水果明确功能：** 大纲中"稀有水果"无功能说明，建议定义为：食用后立即恢复帮工心情/效率 buff 1 天，或作为高级贸易品卖给火山岛（矿工部落需求多样化）。
3. **香料叠加规则明确：** 香料 +50% 是否与粮仓/鱼仓 ×2 叠加？建议：先算 ×2 再算 +50%（即 3 天 → 6 天 → 9 天），并在物品 tooltip 中显示最终保质期。

### 2.2 物价公式缺少边界保护（对应 3.2 / 7.4）

**问题：** `basePrice × (supply / demand)` 无上下限。若玩家把 100 条鱼一次性卖给热带岛，demand 暴涨或 supply 暴涨会导致价格趋近 0 或天文数字，经济崩坏。

**落地方案：**
1. **价格钳制：** `finalPrice = clamp(basePrice × (supply / demand), basePrice × 0.3, basePrice × 3)`。
2. **单次交易限量：** 每个岛每天每类商品收购上限（如热带岛每天最多收 20 条鱼），超出后提示"今天他们不需要更多了"。
3. **价格恢复机制：** supply/demand 每天向基准值回归 20%（模拟市场自我调节），避免一次抛售永久破坏价格。

### 2.3 鱼票系统需要简化操作（对应 3.1 / 7.4）

**问题：** 鱼票 1:1 兑换鱼，但鱼会腐烂。若鱼票不腐烂，玩家会全部换成鱼票导致"鱼票"成为无风险终极货币，架空腐烂系统；若鱼票腐烂，玩家会困惑。

**落地方案：**
1. **明确规则：鱼票不腐烂，但发行量受限。** 鱼仓只能"存鱼发票"，鱼票数量 = 鱼仓中实际存放的鱼数量。玩家用鱼票买货时，对方岛来取鱼仓里的鱼（逻辑上），因此鱼票总量被鱼仓容量（建议 30）天然限制，不会通胀。
2. **一键结算：** 贸易界面支持"一键出售多余物资换取鱼票"，避免逐个拖拽。
3. **统一货币过渡：** 贸易岛建立后，鱼票可按 1:1 兑换统一货币，旧鱼票作废前有 7 天过渡期提示。

### 2.4 岛屿解锁"线索"需要具象化（对应 5.2 / 5.3）

**问题：** "发现热带岛后解锁线索"过于抽象，玩家可能不知道下一步目标。

**落地方案：**
1. **线索物品化：**
   - 热带岛首次贸易后，土著赠送"烧焦的黑色石头"（火山岩样本）→ 大地图上火山岛方位从"？？？"变为可见剪影。
   - 火山岛土著赠送"结冰的兽皮地图"→ 解锁冰雪山岛方位。
2. **任务日志：** 增加简单的"目标追踪"UI（右上角），始终显示当前主线目标（如"建造船（木头 12/30）"），点击可展开科技树。这是模拟经营游戏的标配，大纲中未提及，**强烈建议加入**。

### 2.5 帮工系统过于数值化（对应 1.1 / 4.5）

**问题：** 帮工只有"效率降低 X%"的被动数值，没有个体差异，玩家分配岗位无策略性。

**落地方案（轻量版，不增加太多工作量）：**
1. **特质系统：** 每个帮工随机 1 个特质（从池中抽取）：
   - `老渔民`：雨天/暴风雨捕鱼效率不降
   - `矿工`：采石效率 +30%
   - `樵夫`：砍树效率 +30%
   - `大胃王`：食物消耗 +50%（负面）
   - `耐寒`：冰雪山岛随船时效率不降
2. **岗位分配 UI：** 出发前安排岗位时显示特质匹配提示（绿色=适合，红色=不适合）。
3. 特质在帮工入住时生成并写入存档（JSON 中每个 helper 对象加 `trait` 字段）。

## 三、🟢 可选增强

### 3.1 围栏/野兽提前轻量引入（对应 2.2 / 六、P5）

当前野兽系统排在 P5"预留"，意味着中期玩家没有任何外部威胁，生存压力只来自天气和腐烂。建议：
- **P2 阶段加入"野猪偷作物"事件：** 暴风雨后概率触发，野猪会啃食农田 1~2 天，围栏可完全防御，没有围栏时玩家可手动驱赶（点击交互）。
- 这样围栏建筑在中期就有价值，也为 P5 完整野兽系统铺路。

### 3.2 温泉疗养与"生病"机制（对应 5.2）

大纲提到"温泉可以疗养生病岛民"，但**全文没有定义岛民何时会生病**。建议补充：
- 生病触发条件：吃了红/过期食物（概率 30%）、暴风雨天在外工作、饥饿状态持续 2 天。
- 生病效果：效率降为 0，需静养。
- 疗养方式：温泉（立即治愈）或 3 天自愈（概率 50%）。
- 这给了火山岛贸易线明确的存在价值，也补全了食物腐烂系统的惩罚链条。

### 3.3 存档结构预留字段（对应 7.1）

按大纲"各岛独立 JSON + 共享 game state"的结构，建议在 v1 存档格式中就预留：
```json
{
  "gameState": {
    "day": 0,
    "weather": "sunny",
    "weatherHistory": [],
    "currencies": { "fishTicket": 0, "tradeCoin": 0 },
    "globalFlags": {},          // 预留：岛屿解锁线索、事件标记
    "helpers": [
      { "id": 1, "trait": "", "health": "ok", "post": "fishing" }  // 预留特质/健康
    ],
    "stats": { "fishingSinceLastIron": 0 }  // 预留保底计数器
  },
  "islands": {
    "main": { "resources": {}, "buildings": [], "plots": [] },
    "tropical": { "discovered": false, "trader": null }
  }
}
```
提前定好字段，后期加系统不用迁移存档。

### 3.4 暴风风吹倒树木的恢复逻辑（对应 7.2）

大纲写明"吹倒的树不计入 regrowPending"，即永久损失。建议改为：倒下的树留下"树桩"，可砍伐获得 50% 木头，且树桩 10 天后重新长树。避免玩家辛苦种植的树林被天气永久摧毁产生强烈挫败感。

## 四、开发优先级调整建议（对应第六章）

原优先级表基本合理，建议两处调整：

| 原优先级 | 内容 | 调整后 | 理由 |
|---|---|---|---|
| P0 | 天气 + 食物腐烂 | **P0 增加：保底食物源（采集点）+ 天气保底规则** | 与压力系统同批实现，否则 P0 测试时就会遇到死局 |
| P1 | 造船 + 深海钓鱼 | **P1 增加：铁矿石保底机制 + 目标追踪 UI** | 卡关风险最高的节点，必须与获取途径同步落地 |
| P5 | 野兽/围栏 | **拆分：轻量版"野猪偷作物"提前至 P2** | 中期缺乏外部威胁 |
| — | 生病机制 | **新增至 P3（与火山岛同批）** | 温泉功能需要生病机制支撑 |

**P0 验收标准建议（可直接用于测试）：**
- 连续 10 个游戏日内，玩家不操作时帮工不会全灭
- 暴风雨期间玩家有至少一种可行手段获得食物（采集点/库存加工品）
- 食物腐烂的 HUD 颜色变化在绿→黄→红各阶段肉眼可辨

## 五、总结

大纲 v2.0 的系统耦合设计（天气↔食物↔贸易↔科技）是最大亮点，主要风险集中在三处：

1. **压力系统没有安全网** —— 暴风雨+腐烂+离岛三者叠加可能出现不可挽回的死局，需加保底食物和离岛保护；
2. **关键成长节点靠纯概率** —— 铁矿石获取必须加保底，否则科技树会随机卡死；
3. **探索行为被惩罚** —— 手动航行耗时长且航行期间老家可能崩，需降低航行成本并加事件填充。

其余为体验层优化，可按调整后的优先级表逐步落地。建议 P0 阶段先用纸面数值（Excel 模拟 30 天资源收支）验证生存曲线，再进入代码实现。
