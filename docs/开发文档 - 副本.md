## 一、产品定位

**第一人称体素荒岛养成游戏**。玩家漂流到荒岛，开局零资源，通过捕鱼、种植、伐木、采石、建造让小岛繁荣。

核心设计决策：**经济学原理隐藏在玩法之下**。《小岛经济学》的规律（R1~R8）作为底层引擎，以事件形式涌现，不做直接按钮——玩家只看见鱼和棚屋，看不见"通胀"和"利率"。

### 三层架构

| 层级 | 职责 | 承载文件 | 状态 |

### 3.2 采集系统

**点击采集流程**（2026-09-02 实装）：点击资源 → 计算目标旁站位（`standPointFor`，1.3 单位）→ 黄色选中环 + 自动寻路 → 到位后自动开工。

| 资源 | 耗时/动作 | 产出 | 说明 |
|------|----------|------|------|
| 树 | 连挥 3 斧（0.45s/击） | +3 木头 | 斧头挥砍动画，树晃 → 倒地，4 天后重生 |
| 石头 | 连敲 4 锤（0.45s/击） | +2 石头 | 锤击 + 火星粒子，6 天后重生 |
| 野果丛 | 即时 | +1 谷穗 | 既能吃也能当种子，2 天后重生 |
| 农田播种 | 挖坑 0.8s + 播种 0.7s | -1 谷穗 | 弯腰动画，3 天后成熟 |
| 农田收获 | 即时 | +6 谷穗 | 田变回荒地，可重新播种 |
| 鱼 | 概率捕捉 | 徒手 1 / 渔网 2 / 码头 3 条 | 见下 |

**捕鱼系统**（鱼保持手动，不做自动追击）：
- 成功率 = 35% + 20% × 失败次数，封顶 95%
- 鱼有 AI：巡游、边界折返（13.6~19 环带）、延迟躲避（0.25s 反应，防过敏）、受惊逃窜
- 陆地模式：准星对准鱼，按空格
- 游泳模式：游近到 3.2 单位内，按空格

### 3.3 建造系统

| 建筑 | 造价 | 效果 |
|------|------|------|
| 渔网 | 木 2 | 捕鱼 ×2 |
| 棚屋 | 木 4 石 2 | 住 2 人，吸引新岛民的前提 |
| 粮仓 | 木 6 石 4 | 繁荣度 +30（Phase 2 将作为鱼仓） |
| 码头 | 木 8 | 捕鱼 ×3，繁荣度 +30 |

### 3.4 人口与雇佣系统（Phase 1.5）

**岛民来源**：有余粮（≥ 人口+2）+ 有空床位 → 每天自动上岛一位，人口上限 12。

**职业表**：

| 职业 | 日常产出 | 分成/成本 | 繁荣度 |
|------|---------|----------|--------|
| 散工（默认） | 自给自足，产 1 吃 1 | 净零 | 10 |
| 渔夫 | `P = round(2 × 资本 × 边际效率)` | 玩家得 `round(P × 0.6)`，P≥2 时自食 | 15 |
| 农夫 | 照看 4 块田：熟田收 +4 谷/田并补种，荒田代播种 | 吃库存 1 份 | 15 |
| 樵夫 | +1 木头 | 管 1 顿饭 | 15 |
| 采石工 | +1 石头 | 管 1 顿饭 | 15 |

**规则**：
- 安家费 5 份食物（鱼优先，谷穗可补）
- 同职业第 N 人效率 `× max(0.5, 1 − 0.1×(N−1))`，防单职业堆人
- 断粮连续 2 天：帮工先散伙退回散工，全部散伙后才轮到岛民离岛
- 口粮公式：`need = 1（玩家）+ 散工数 + 需供养帮工数`

**实体呈现**（方案 B）：
- 带四肢的方块小人，职业配色（渔夫橙/农夫黄/樵夫棕/矿工灰/散工蓝）
- 头顶几何徽章（鱼/谷穗/木料/矿石），上下浮动
- 工作状态机：直线走向工作点 → 干活动画（樵夫矿工 0.45s/击带火星、农夫弯腰、渔夫甩竿）→ 4~8s 换点
- 晨间产出飘字（Canvas Sprite，4.5s 上飘淡出）

### 3.5 表现层

- **体素小岛**：InstancedMesh 双层，半径 13（草地 ≤9，沙滩 9~13，泥土底层）
- **海水**：水线 12.3，近海外径 20（游不出近海）
- **角色动画**：MC 经典比例（头 0.5/躯干 0.75/四肢 0.75），四肢挂枢轴便于摆动
  - 三态：待机 / 行走（双脚交替迈步）/ 游泳（水平趴浮 + 划水 + 打水）
  - 动作覆盖：挥斧、抡锤、弯腰挖坑播种
  - 平滑转身用最短角插值 `((diff+π) % 2π + 2π) % 2π − π`
- **视角**：灵敏度 0.0015 rad/px，左下角滑块可调（0.0003~0.0030），localStorage 记忆；单次事件钳制 50px 防疯转
- **速度**：陆地 8，游泳 4，帮工 2.6

## 六、未来开发规划

### Phase 2：经济苏醒（下一步）

把 `economy.js` 接入表层，以**事件形式涌现**，不新增"银行""通胀"这类按钮。

| 书中机制 | 游戏内呈现 | 解锁条件 |
|---------|-----------|---------|
| 储蓄 / 利率 | **鱼仓**：存鱼生息、赊鱼付息 | 粮仓建成 |
| 印钞 / 通胀 | **印鱼坊**：鱼票换真鱼，物价上涨 | 繁荣度 ≥ 120 |
| 棚屋泡沫 | **赊棚**、岛主担保、崩盘 | 繁荣度 ≥ 120 |
| 外资流入 | **邻岛通商**：鱼换木/石、回借/抽鱼 | 码头建成 |

建议实施顺序：**鱼仓 → 印鱼坊 → 赊棚 → 通商**。鱼仓是后面通胀和泡沫的地基，能让玩家立刻感受到"储蓄有意义"。

### Phase 3：土地危机三路线

人口增长后土地不够，三条路线按成本升序：

**A 效率深耕**（资本深化，成本最低）
- 粮塔：木 8 石 4/层，每层 +4 块立体田
- 灌溉渠：木 6，全田生长 −1 天
- 大网：木 8，捕鱼 ×3

**B 邻岛贸易**（比较优势，不占本岛地）
- 商船定期到港，鱼换木/石，汇率随通商天数渐优
- 与 economy.js R8 接轨

**C 填海造陆**（终局成就玩法）
- 条件：码头 + 繁荣度 ≥ 220
- 成本：半径 +2 一圈，耗木 20 石 10 + 全员 3 天工期（期间产出减半）
- 技术：地形为数据驱动 InstancedMesh，重建 `land` 数组即可

> **设计意图**：C 在数值上永远劣于 A/B——资本效率优先于蛮力扩张，这是书中最核心的观点，不能让填海变成最优解。

## 七、设计铁律与命名规范

### 三条铁律

1. **延迟消费才配有资本**——织网必须付出代价，白送就丢了核心教学
2. **鱼不腐坏**——这是储蓄能成立的前提，不要加保鲜机制
3. **skill 是唯一事实来源**——改数值先改 `xiaodao-economics/SKILL.md`，再改代码

### 命名规范（面向小白，禁用金融词）

UI/日志/招牌中**禁止出现**：银行、房贷、首付、断供、通胀、两棚、外资、撤资。

| 书中/金融术语 | 游戏内命名 |
|-------------|-----------|
| 银行 | 鱼仓 |
| 中央银行 | 印鱼坊 |
| 房贷 | 赊棚 |
| 首付 | 押鱼（两成押鱼 / 零押鱼） |
| 断供 | 还不上鱼 |
| 政府担保（两棚） | 岛主担保 |
| 外资 | 邻岛回借 |
| 撤资 | 抽鱼 |
| 贸易 | 通商 |
| 通胀 | 物价 +X% |
| 鱼本位 | 兑鱼保证：1 票 = 1 鱼 |
| 房价指数 | 棚价热度 ×N |
| 房价收入比 | X 天收成 |

### 反模式（必须避免）

- ❌ 把通胀做成物价随机上涨，而不关联货币超发
- ❌ 让玩家无代价获得渔网
- ❌ 储蓄与借贷无利率差、无稀缺度联动
- ❌ 棚屋泡沫缺少"真实产出未增"这条根因

## 八、技术架构与开发约定

### 技术栈

- **Three.js r0.160**（ES Module + importmap，已本地化到 `vendor/`，离线可玩）
- 纯前端，无构建步骤，`启动.bat` 起本地 http 服务（8080）
- 状态与渲染分离：`game.js` 纯逻辑无 DOM，`main.js` 负责 3D

### 关键实现约定

| 约定 | 原因 |
|------|------|
| 射线检测前必须 `camera.updateMatrixWorld(true)` | 否则 `matrixWorldInverse` 是上一帧旧值，第三人称相机跳变会导致射线方向完全错误 |
| 游泳常量硬编码 `DEEP_WATER = 20`，不可引用 `R` | `const` 的 TDZ，前向引用会导致模块加载崩溃（卡开始界面） |
| 农田 `age = -1` 表示荒田，`0` 表示当天刚种 | 农夫代播种依赖此区分 |
| 主循环顺序：移动 → 相机 → 动画 → AI → 特效 → 动作推进 → 提示 → 渲染 | 顺序敏感，改动需谨慎 |

### 测试方法

- 语法检查：`cp src/main.js check.tmp.mjs && node --check check.tmp.mjs`（Windows 下 `/tmp` 路径 node 不识别，须用项目内临时文件）
- 逻辑自测：`game.js` / `economy.js` 为纯逻辑，cp 成 `.mjs` 后可直接 node 导入跑全链路模拟
- 3D 层无法无头测试，靠浏览器验证
