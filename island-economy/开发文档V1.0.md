## 一、产品定位

第一人称体素荒岛养成游戏。玩家漂流到荒岛，开局零资源，通过捕鱼、种植、伐木、采石、建造让小岛繁荣。

核心设计决策：经济学原理隐藏在玩法之下。《小岛经济学》的规律（R1~R8）作为底层引擎，以事件形式涌现，不做直接按钮——玩家只看见鱼和棚屋，看不见"通胀"和"利率"。

**体验定位一句话**：玩家在一个符合经济学因果律的沙盒里，用自己的方式验证规律——保留"为什么"，重构"怎么玩"。

**目标玩家画像**：

- 主目标：对经营/养成类游戏有兴趣、但无经济学背景的普通玩家（16~35岁）
- 次目标：读过《小岛经济学》、想"亲手体验书中世界"的读者
- 非目标：硬核经济模拟爱好者（本作不追求数值深度）

## 三、体验设计总纲

> 本章是整份文档的设计灵魂。所有系统设计的优先级判断标准：**先保证好玩，再保证正确，最后保证深刻。**

### 3.0 核心体验原则

| 原则      | 含义                 | 反例           |
| ------- | ------------------ | ------------ |
| 因果可感知   | 每个经济机制必须有玩家可观察到的后果 | 利率变了但玩家无任何感知 |
| 失败即信息   | 错误选择带来的是"理解"而非"惩罚" | 直接Game Over  |
| 延迟满足有回报 | 储蓄/投资的回报必须显著且可视化   | 存鱼10天只多0.5条  |
| 涌现而非说教  | 玩家自己发现规律，而非被弹窗告知   | "提示：这就是通货膨胀" |
| 节奏先于正确  | 若原著逻辑导致体验断裂，优先调整节奏 | 连续5天无事发生     |

### 3.1 新手保护与生存缓冲

原著中艾伯饿肚子织网是"延迟消费"的美德，但游戏中若连续3天没鱼吃就死亡，是劝退而非教学。

| 机制    | 设计                          | 对应原著          |
| ----- | --------------------------- | ------------- |
| 保底采集  | 徒手捕鱼成功率35%起步，失败累积+20%，封顶95% | 已实装           |
| 新手丰饶期 | 前5天资源再生速度×1.5，鱼群上限+4        | 对应"原始积累红利"    |
| 饥饿不致死 | 断粮时体力上限-30%、移动速度-20%，而非死亡   | 对应"风险有代价但不致命" |
| 织网有保底 | 织网当天仍可采集（但**捕鱼成功率减半**，`craftingDay`，睡一觉恢复） | 降低R2的入门门槛，已实装 |

### 3.2 反馈层设计（经济事件如何被感知）

**核心原则：不用文字解释概念，用感官传递信息。**

| 经济事件   | 玩家感知方式                         | 禁止方式        |
| ------ | ------------------------------ | ----------- |
| 利率变化   | 鱼仓里的鱼每天"生出"小鱼苗（视觉），数量随利率变化     | 弹窗"当前利率10%" |
| 通胀发生   | 商店物品旁出现红色↑箭头；NPC抱怨"以前一条鱼能买俩椰子" | 弹窗"通胀率+15%" |
| 棚屋泡沫膨胀 | 建造棚屋的动画变得金光闪闪、浮夸，但产出效率条几乎不动    | 文字说明"泡沫形成中" |
| 棚屋崩盘   | 棚屋模型变灰、缩小，周围出现裂纹粒子；帮工叹气动画      | 弹窗"泡沫破裂"    |
| 储蓄不足   | 角色动作变慢、弯腰喘气动画；屏幕边缘轻微暗角         | 直接扣血/死亡     |
| 外资流入   | 码头出现外国商船模型，带来新资源；利率条（若有）微微下移   | 文字"外资压低利率"  |
| 外资撤离   | 商船加速离开，留下空荡荡的码头；物价箭头变红加速       | 文字"资本外逃"    |

### 3.3 节奏控制：时间压缩与周期设计

原著时间跨度数十年，游戏单局目标30~60分钟。必须对经济周期进行压缩。

| 原著周期         | 游戏内压缩     | 设计理由                     |
| ------------ | --------- | ------------------------ |
| 储蓄→投资→回报（数年） | 3~5个游戏日   | 一个session内完成完整正循环        |
| 通胀累积（数年）     | 8~12个游戏日  | 让玩家在"不知不觉"中感受到           |
| 泡沫形成→崩盘（数年）  | 10~15个游戏日 | 足够长以建立"安全感"，足够短以在耐心耗尽前爆发 |
| 贸易依赖→断裂（数年）  | 15~20个游戏日 | 作为终局事件，需要足够铺垫            |

**周期性波动设计**：每12~15天进入一次"淡季"（鱼类减少、需求下降），持续2~3天。

- 有储蓄的玩家：平稳度过，感受到"存鱼的意义"
- 无储蓄的玩家：被迫缩减开支，体验"资本不足"的后果
- 淡季结束后：自动生成"岛屿周报"（简洁数据对比），作为隐性教学

### 3.4 玩家决策的"对比实验"设计

与其让玩家自己摸索出"填海造陆不如深化资本"，不如提供**可控的对比场景**：

| 触发时机     | 事件       | 选项A             | 选项B              | 结果呈现       |
| -------- | -------- | --------------- | ---------------- | ---------- |
| 繁荣度≥120  | "邻岛商人来访" | 接受大量贝壳换土地（短期暴利） | 拒绝，用资源改良渔网（长期收益） | 10天后产出对比图表 |
| 棚屋价格×1.5 | "棚屋投资热潮" | 借钱买第二间棚屋        | 把钱存入鱼仓           | 崩盘后资产对比    |
| 通商开启后    | "单一依赖风险" | 只和邻岛做鱼换木        | 同时发展本岛伐木         | 邻岛抽鱼时的生存对比 |

关键规则：**两个选项都不致命**，但结果差异必须直观可量化。

### 3.5 "非最优解"的叙事价值

原著批判的行为（过度借贷、盲目扩张）在游戏中不应只是惩罚，应提供**独特的叙事体验**：

| "错误"行为 | 独特奖励                | 教学价值                  |
| ------ | ------------------- | --------------------- |
| 疯狂借贷   | 解锁"奢华派对"特殊事件、岛上出现烟花 | 体验"虚假繁荣"的快感→理解为何人们会上当 |
| 填海造陆   | 触发"生态异变"隐藏剧情、新地形探索  | 理解"蛮力扩张"的代价和独特乐趣      |
| 拒绝所有储蓄 | 解锁"及时行乐"对话线、特殊角色互动  | 理解消费主义为何有吸引力          |
| 过度依赖外资 | 触发"邻岛使节"专属剧情线       | 理解依附关系的政治含义           |

**点击采集流程**：点击资源 → 计算目标旁站位（`standPointFor`，1.3 单位）→ 黄色选中环 + 自动寻路 → 到位后自动开工。

| 资源 | 耗时/动作 | 产出 | 说明 |
|------|----------|------|------|
| 树 | 连挥 3 斧（0.45s/击） | +3 木头 | 斧头挥砍动画，树晃 → 倒地，4 天后重生 |
| 石头 | 连敲 4 锤（0.45s/击） | +2 石头 | 锤击 + 火星粒子，6 天后重生 |
| 野果丛 | 即时 | +1 谷穗 | 既能吃也能当种子，2 天后重生 |
| 农田播种 | 挖坑 0.8s + 播种 0.7s | -1 谷穗 | 弯腰动画，3 天后成熟 |
| 农田收获 | 即时 | +6 谷穗 | 田变回荒地，可重新播种 |
| 鱼 | 概率捕捉 | 徒手 1 / 渔网 2 / 码头 3 条 | 见下 |

**捕鱼系统**（鱼保持手动，不做自动追击）：

- 成功率 = 35% + 20% × 失败次数，封顶 95%
- 鱼有 AI：巡游、边界折返（13.6~19 环带）、延迟躲避（0.25s 反应，防过敏）、受惊逃窜
- 陆地模式：准星对准鱼，按空格
- 游泳模式：游近到 3.2 单位内，按空格

### 4.4 人口与雇佣系统（Phase 1.5）

**岛民来源**：有余粮（≥ 人口+2）+ 有空床位 → 每天自动上岛一位，人口上限 12。

| 职业 | 日常产出 | 分成/成本 | 繁荣度 |
|------|---------|----------|--------|
| 散工（默认） | 自给自足，产 1 吃 1 | 净零 | 10 |
| 渔夫 | `P = round(2 × 资本 × 边际效率)` | 玩家得 `round(P × 0.6)`，P≥2 时自食 | 15 |
| 农夫 | 照看 4 块田：熟田收 +4 谷/田并补种，荒田代播种 | 吃库存 1 份 | 15 |
| 樵夫 | +1 木头 | 管 1 顿饭 | 15 |
| 采石工 | +1 石头 | 管 1 顿饭 | 15 |

**规则**：

- 安家费 5 份食物（鱼优先，谷穗可补）
- 同职业第 N 人效率 `× max(0.5, 1 − 0.1×(N−1))`，防单职业堆人
- 断粮连续 2 天：帮工先散伙退回散工，全部散伙后才轮到岛民离岛
- 口粮公式：`need = 1（玩家）+ 散工数 + 需供养帮工数`

**实体呈现**（方案 B）：

- 带四肢的方块小人，职业配色（渔夫橙/农夫黄/樵夫棕/矿工灰/散工蓝）
- 头顶几何徽章（鱼/谷穗/木料/矿石），上下浮动
- 工作状态机：直线走向工作点 → 干活动画（樵夫矿工 0.45s/击带火星、农夫弯腰、渔夫甩竿）→ 4~8s 换点
- 晨间产出飘字（Canvas Sprite，4.5s 上飘淡出）

### 4.5 表现层

- **体素小岛**：InstancedMesh 双层，半径 13（草地 ≤9，沙滩 9~13，泥土底层）
- **海水**：水线 12.3，近海外径 20（游不出近海）
- **角色动画**：MC 经典比例（头 0.5/躯干 0.75/四肢 0.75），四肢挂枢轴便于摆动
  - 三态：待机 / 行走（双脚交替迈步）/ 游泳（水平趴浮 + 划水 + 打水）
  - 动作覆盖：挥斧、抡锤、弯腰挖坑播种
  - 平滑转身用最短角插值 `((diff+π) % 2π + 2π) % 2π − π`
- **视角**：灵敏度 0.0015 rad/px，左下角滑块可调（0.0003~0.0030），localStorage 记忆；单次事件钳制 50px 防疯转
- **速度**：陆地 8，游泳 4，帮工 2.6

## 七、未来开发规划

### Phase 2：经济苏醒（下一步）

把 `economy.js` 接入表层，以事件形式涌现，不新增"银行""通胀"这类按钮。

| 书中机制    | 游戏内呈现            | 解锁条件      |
| ------- | ---------------- | --------- |
| 储蓄 / 利率 | 鱼仓：存鱼生息、赊鱼付息     | 粮仓建成      |
| 印钞 / 通胀 | 印鱼坊：鱼票换真鱼，物价上涨   | 繁荣度 ≥ 120 |
| 棚屋泡沫    | 赊棚、岛主担保、崩盘       | 繁荣度 ≥ 120 |
| 外资流入    | 邻岛通商：鱼换木/石、回借/抽鱼 | 码头建成      |

建议实施顺序：鱼仓 → 印鱼坊 → 赊棚 → 通商。鱼仓是后面通胀和泡沫的地基，能让玩家立刻感受到"储蓄有意义"。

**Phase 2 最小可验证版本（MVP）**：

- 目标：仅接入鱼仓（储蓄+利率），验证"玩家是否能在3~5天内自主发现存鱼比吃鱼划算"
- 验证标准：测试玩家在不看说明的情况下，主动将鱼存入鱼仓
- 预计工期：3~5天
- 通过后再推进印鱼坊

**Phase 2 各子系统的接入规格**：

#### 2.1 鱼仓（储蓄/利率）

| 项目     | 设计                                       |
| ------ | ---------------------------------------- |
| 入口     | 粮仓建成后，点击粮仓出现"存鱼/取鱼"选项                    |
| 利率呈现   | 不显示百分比。存鱼后次日，鱼仓旁出现"+1小鱼苗"飘字；利率高时鱼苗多，低时少  |
| 利率浮动   | 随岛上总储蓄量变化：储蓄少→利率高（鼓励存）；储蓄多→利率低（鼓励投）      |
| 赊鱼（借贷） | 需消耗繁荣度≥80解锁。赊鱼需还本+息，还不上时帮工效率下降           |
| 首次体验钩子 | 粮仓建成当天，触发事件："老岛民建议你存点鱼以备不时之需"（仅提示一次，不强制） |

#### 2.2 印鱼坊（通胀）

| 项目   | 设计                                |
| ---- | --------------------------------- |
| 触发条件 | 繁荣度≥120，且岛上出现过"物资紧缺"事件（如淡季）       |
| 呈现方式 | 岛上出现新建筑"印鱼坊"，NPC解释"可以用鱼票换东西，更方便"  |
| 通胀感知 | 物价以"天"为单位缓慢上涨，表现为商店数字变化+红色箭头      |
| 玩家选择 | 可以主动"印鱼"（获得短期资源但物价上涨），也可以拒绝       |
| 关键教学 | 玩家若连续印鱼3次以上，触发"物价飞涨"事件，所有物品价格×1.5 |

#### 2.3 赊棚（棚屋泡沫）

| 项目     | 设计                                     |
| ------ | -------------------------------------- |
| 触发条件   | 印鱼坊存在 + 棚屋≥3                           |
| 呈现方式   | 出现"赊棚"选项：付两成押鱼即可入住新棚屋，每天还鱼             |
| 泡沫膨胀信号 | 棚屋价格每3天自动上涨10%；建造动画越来越浮夸               |
| 岛主担保   | 繁荣度≥180时解锁"零押鱼"选项（对应书中政府担保），利息由 8% 减半至 4% |
| 崩盘触发   | 当棚屋总价/岛日产出的比值 ≥ CRASH_RATIO(20) 时，触发崩盘 |
| 崩盘表现   | 棚屋模型变灰、价格暴跌55%、帮工叹气、"岛屿周报"显示损失         |
| 崩盘后    | 提供"重建"选项（需储蓄），引导玩家理解"储蓄是安全网"           |

#### 2.4 邻岛通商（外资）

| 项目   | 设计                                             |
| ---- | ---------------------------------------------- |
| 触发条件 | 码头建成                                           |
| 呈现方式 | 商船定期靠岸（每5天一次），提供鱼换木/石的交易                       |
| 回借机制 | 邻岛主动提出"借鱼给你，以后还"，利率低于本岛鱼仓                      |
| 抽鱼触发 | 当本岛通胀率（物价涨幅）≥ CONFIDENCE_TRIGGER(1.3) 时，邻岛开始抽鱼 |
| 抽鱼表现 | 商船不再靠岸，已借的鱼需加速偿还，利率飙升                          |
| 关键教学 | 让玩家体验"便宜的钱"→"依赖"→"突然断供"的完整链条                   |

### Phase 3：土地危机三路线

人口增长后土地不够，三条路线按成本升序：

**A 效率深耕（资本深化，成本最低）**

- 粮塔：木8 石4/层，每层+4块立体田
- 灌溉渠：木6，全田生长−1天
- 大网：木8，捕鱼×3

**B 邻岛贸易（比较优势，不占本岛地）**

- 商船定期到港，鱼换木/石，汇率随通商天数渐优
- 与 economy.js R8 接轨

**C 填海造陆（终局成就玩法）**

- 条件：码头 + 繁荣度≥220
- 成本：半径+2一圈，耗木20 石10 + 全员3天工期（期间产出减半）
- 技术：地形为数据驱动 InstancedMesh，重建 `land` 数组即可

设计意图：C在数值上永远劣于A/B——资本效率优先于蛮力扩张，这是书中最核心的观点，不能让填海变成最优解。

**C路线的"值得体验"设计**（解决"永远次优→无人选择"的问题）：

| 设计                               | 目的           |
| -------------------------------- | ------------ |
| 填海完成后触发"新生态"事件：新地形上出现独有资源（如稀有贝壳） | 提供A/B没有的探索奖励 |
| 填海过程中触发"全员协作"特殊动画和对话             | 提供情感价值       |
| 若玩家在崩盘后选择填海，触发"废墟重建"专属剧情线        | 提供叙事独特性      |
| 填海成就解锁"岛主"称号和特殊岛屿外观              | 提供收集/成就动力    |

## 八、设计铁律与命名规范

### 铁律（扩展为五条）

1. **延迟消费才配有资本**——织网必须付出代价，白送就丢了核心教学
2. **鱼不腐坏**——这是储蓄能成立的前提，不要加保鲜机制
3. **skill 是唯一事实来源**——改数值先改 `xiaodao-economics/SKILL.md`，再改代码
4. **好玩优先于正确**——若某条经济逻辑导致连续3天无正反馈，必须调整节奏而非坚持逻辑
5. **感知优先于理解**——玩家不需要知道"这是通胀"，只需要感受到"鱼不值钱了"

### 命名规范（面向小白，禁用金融词）

（保留原文档命名表，不做修改。）

### 反模式（扩展）

❌ 把通胀做成物价随机上涨，而不关联货币超发  
❌ 让玩家无代价获得渔网  
❌ 储蓄与借贷无利率差、无稀缺度联动  
❌ 棚屋泡沫缺少"真实产出未增"这条根因  
❌ 经济事件发生后无任何视觉/文字反馈，玩家完全不知道发生了什么  
❌ 连续超过3个游戏日无任何新事件、新选择或新解锁  
❌ "错误选择"只给惩罚不给独特体验（导致玩家不敢探索）  
❌ 用弹窗/教程直接解释经济学概念（违反"涌现"原则）

## 九、技术架构与开发约定

### 9.1 技术栈

- **Three.js r0.160**（ES Module + importmap，已本地化到 `vendor/`，离线可玩）
- 纯前端，无构建步骤，`启动.bat` 起本地 http 服务（8080）
- 状态与渲染分离：`game.js` 纯逻辑无 DOM，`main.js` 负责 3D

### 9.2 关键实现约定

| 约定 | 原因 |
|------|------|
| 射线检测前必须 `camera.updateMatrixWorld(true)` | 否则 `matrixWorldInverse` 是上一帧旧值，第三人称相机跳变会导致射线方向完全错误 |
| 游泳常量硬编码 `DEEP_WATER = 20`，不可引用 `R` | `const` 的 TDZ，前向引用会导致模块加载崩溃（卡开始界面） |
| 农田 `age = -1` 表示荒田，`0` 表示当天刚种 | 农夫代播种依赖此区分 |
| 主循环顺序：移动 → 相机 → 动画 → AI → 特效 → 动作推进 → 提示 → 渲染 | 顺序敏感，改动需谨慎 |

### 9.3 测试方法

- 语法检查：`cp src/main.js check.tmp.mjs && node --check check.tmp.mjs`（Windows 下 `/tmp` 路径 node 不识别，须用项目内临时文件）
- 逻辑自测：`game.js` / `economy.js` 为纯逻辑，cp 成 `.mjs` 后可直接 node 导入跑全链路模拟
- 3D 层无法无头测试，靠浏览器验证

## 十二、原著逻辑的游戏化取舍表

> 此表记录所有"为了好玩而偏离原著"的决策及其理由，供后续开发时快速查阅。

| 原著逻辑          | 游戏中的调整                      | 理由                       |
| ------------- | --------------------------- | ------------------------ |
| 储蓄是唯一美德，消费即浪费 | 允许适度消费维持士气，但过度消费导致发展停滞      | 纯禁欲主义违背心流；保留"储蓄带来长期优势"即可 |
| 政府干预必然导致灾难    | 将"政府"改为可选的"社区互助"，有正面效果也有副作用 | 绝对化批判失去策略深度；保留"干预有代价"的认知 |
| 外贸=掠夺/依赖      | 设计互利贸易，但设置"单一依赖"风险阈值        | 教会"多元化抗风险"比"贸易有害"更有教育意义  |
| 货币超发=纯粹邪恶     | 通胀初期有短暂繁荣假象，后期才显现恶果         | 还原真实周期的迷惑性，比单纯妖魔化更有教学价值  |
| 个人奋斗决定一切      | 加入随机天气/灾害，但强调准备度影响结果        | 突出"风险管理"而非"宿命论"          |
| 艾伯必须完全饿肚子才能织网 | 织网当天产出减半但不归零                | 降低入门挫败感，保留"有代价"的核心       |
| 棚屋崩盘后经济长期萧条   | 崩盘后5~8天即可开始重建               | 游戏节奏不允许长期停滞              |
